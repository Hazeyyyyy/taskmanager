Project Title
- Task Management API

Description
- The Task Management API is a simple RESTful API built using Node.js and Express.js. It allows users to create, view, update, and delete tasks. The API uses an in-memory array to store task data. Each task contains an ID, task text, category, and completion status.

Technologies Used
- Node.js
- Express.js
- JavaScript
- Postman
- Git and GitHub
- Render

Installation

git clone https://github.com/Hazeyyyyy/taskmanager.git

Limitations
1. The API currently stores tasks in memory.
2. Data will be lost when the server is restarted.
3. The project does not use a database.
4. Authentication and user accounts are not included.
